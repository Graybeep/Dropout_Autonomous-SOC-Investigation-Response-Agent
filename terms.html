Terms of use

This is a project built for a hackathon, published so its output can be read. It is not a product and nothing is sold here.

What this is

A prototype autonomous SOC investigation agent, together with a viewer that replays traces of its runs. The site is a read-only record of work the agent did against synthetic fixtures. There is no service running behind it, no account to create, and nothing to buy.

Not security advice

The verdicts, scores and firewall actions shown are the output of a prototype reasoning over invented data. They are not an assessment of any real system and must not be relied on to decide whether anything in the real world is compromised, patched or safe. The CVE references in the fixtures are used illustratively and the version ranges attached to them were written for this project; do not treat them as an accurate vulnerability source.

Running it yourself

The agent runs locally and needs your own API key. Any cost or usage that follows from running it is yours, and the key never touches this site: the hosted build contains static files only, and no part of the agent loop is deployed.

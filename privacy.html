Privacy

Short, because this site does very little. It serves static files and nothing else.

What this site collects

AccountsNone. There is nothing to sign in to.
CookiesNone set by this site.
AnalyticsNone. No tracking or measurement script runs.
FormsNone. There is no input field anywhere on the site.
Third partiesNone. Every script, style and font falls back to local or system resources, so no request leaves the page.

Browser storage

The trace viewer keeps nothing in localStorage, sessionStorage or IndexedDB. Which scenario you are looking at is held in the page URL, so it stays in your browser history exactly as any other URL does.

Hosting

The site is hosted on Vercel. Like any web host, Vercel receives the requests your browser makes in order to serve the files, and may log them according to its own policies. That is outside this project's control and is the only place a record of your visit could exist.

The data you can see here

Every hostname, IP address, CVE reference, log line and account name in the traces is synthetic. They were written as fixtures for this project. No real network, host, person or organisation is described anywhere on this site.

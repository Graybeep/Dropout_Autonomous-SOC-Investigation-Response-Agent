Autonomous investigation & response

An alert says you were attacked.
Did it actually work?

This agent takes a simulated intrusion-detection alert and decides whether the attack actually succeeded, by correlating it against asset, vulnerability, configuration and log evidence, instead of trusting the alert's own severity label.

This viewer replays traces from real agent runs. Every step shown was produced by the live system, not simulated. The agent itself runs locally: clone the repo, set an API key from whichever provider you like, and run python run_all.py. It speaks both the OpenAI and Anthropic APIs, so switching provider is one line of config.

The short version

A severity label is an opinion, not a finding

A “critical” injection alert against a host patched two years ago, whose logs show the request was blocked, is a false alarm. A quieter alert against an unpatched host that then shipped two megabytes outbound is a breach. The label does not decide which is which the correlated evidence does, and the agent has to go and get it.

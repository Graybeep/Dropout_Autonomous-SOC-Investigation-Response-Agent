### Sufficiency assessments

> **Alert summary:** SQL injection attempt (UNION SELECT) from 198.51.100.23 to 10.20.2.22:3306 on asset SRV-DB-02, labeled "critical" by the sensor.

**Hypothesis:** For this to have SUCCEEDED, three things must hold:
1. **Vulnerability present** — SRV-DB-02 must be running a MySQL version inside the affected range for a UNION-SQLi-relevant CVE.
2. **Host execution** — the host's logs must show a malicious query that actually executed/returned rows (not a parse error or a 403-style rejection).
3. **Data movement** — packet metadata must show a payload anomaly or outbound exfiltration, not a small error response.

**Falsifiers:** a patched version outside all affected ranges; logs showing the query erroring out or being blocked; benign packet flow with no data leaving.

I'll start with the version facts, since they gate everything else.

> **Version comparison (done explicitly):**

- SRV-DB-02 runs **mysql 5.7.21**.

### Sufficiency assessments

> The alert is a SQL injection attempt (UNION SELECT) against SRV-DB-05 on port 3306 (MySQL). The "high" label is the sensor's opinion only.

**Hypothesis:** For this attack to have SUCCEEDED, three things must hold:
1. SRV-DB-05 must be running a MySQL version that is actually vulnerable (inside a CVE's affected range) — or at minimum the app endpoint must be injectable.
2. Host logs must show the injected query actually executing / returning data.
3. Packet metadata must show data flowing back out (exfil) rather than a small error response.

**Falsifiers:** If the running version is outside all affected ranges → not vulnerable. If logs show the query erroring out or zero rows → failed. If packet metadata shows only a tiny error response → failed.

Let me gather the independent facts in parallel.

> Key results so far:

**Version join — SRV-DB-05 runs MySQL 5.7.22:**
- CVE-2023-21980 affects `>=5.7.0,<5.7.30` → **5.7.22 IS inside this range**. This CVE is exactly `sql_injection` with "arbitrary read of arbitrary tables by an unauthenticated remote attacker" — a perfect match for a UNION SELECT injection.
- CVE-2022-21444 affects `>=8.0.0,<8.0.30` → 5.7.22 is outside (different major line, and it's DoS-only anyway).

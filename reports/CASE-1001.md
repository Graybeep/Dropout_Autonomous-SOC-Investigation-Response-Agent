### Sufficiency assessments

> **Hypothesis forming.** A "UNION SELECT" SQL-injection attempt against SRV-WEB-01 on 443. For this attack to have SUCCEEDED, all of the following must hold:

1. The web app must actually pass the injected UNION SELECT to a backend database — and the backend DB version must be inside an affected range for a SQLi-relevant CVE (or at minimum be reachable/queryable).
2. Host logs must show an injected query actually *executing* and returning data (rows returned), not a 403/500 or a syntax error.
3. Packet metadata should show asymmetry consistent with data flowing *back* to 203.0.113.45.
4. History: prior alerts may show whether this host is repeatedly targeted/successfully compromised.

**What would falsify it:** logs showing the request blocked/rejected/errored, a backend DB version outside all affected ranges, or a tiny outbound-only flow with no response payload.

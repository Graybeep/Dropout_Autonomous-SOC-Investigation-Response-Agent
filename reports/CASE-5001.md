> The alert is a low-severity MySQL port-3306 enumeration scan against `SRV-WEB-04`. Note the mismatch worth flagging: a *web* server being hit on the *MySQL* port. Let me state the hypothesis.

**Hypothesis:** For this attack to have SUCCEEDED, three things must all be true:
1. `SRV-WEB-04` must actually be running a vulnerable MySQL version reachable on 3306 (not just be scanned blind).
2. The host logs must show the attacker *did* something — a completed auth, a query that executed, rows returned — not just a connection attempt.

**Confirmation:** a running MySQL version inside a CVE's affected range, logs showing executed queries/returned rows, and packet metadata showing outbound payload.
**Falsification:** the running MySQL version is outside all affected ranges (patched); or logs show the attempt errored/returned zero rows; or packet metadata shows a tiny failed flow.
